## Campus Events Website

### Project Description
Campus Events is a college event website developed as part of Assessment 1 during Doodle Blue training. It provides information about upcoming technical, cultural, sports, and workshop events happening on campus.

The website allows users to explore events, view event details, check the event schedule, and fill out a registration form.

### Technologies Used
- HTML5 – Structure of the website
- CSS3 – Styling, layout, and responsive design
- JavaScript – DOM manipulation, event handling, and form validation

### Features
- Home page with featured events and event categories
- About page with information about Campus Events
- Events page displaying upcoming events
- Event details page with event descriptions, dates, times, venues, and categories
- Schedule page displaying event schedules
- Registration form with input fields and validation
- Search functionality to find events
- Interactive event cards with mouse and click events
- Responsive layout for different screen sizes

### JavaScript Concepts Implemented
The following concepts were implemented as part of the assessment:

1. **Double-click event (`dblclick`)** – Highlights an event card when double-clicked.
2. **Context menu event (`contextmenu`)** – Displays a custom message when an event card is right-clicked.
3. **Mouseover and mouseout events** – Changes the event card shadow and displays messages when the pointer moves over or away from a card.
4. **Mouseenter and mouseleave events** – Adds and removes a CSS class when the pointer enters or leaves an event card.
5. **Forms** – Collects user details through the event registration form.
6. **DOM manipulation** – Updates messages, styles, and CSS classes dynamically using JavaScript.
7. **Regular expressions** – Validates the user's name, email address, mobile number, and password.

### How to Run the Project
1. Clone or download this repository.
2. Open the project folder.
3. Open `index.html` in a web browser.
4. Navigate through the website using the navigation menu.

### Form Validation
The registration form validates the entered details using JavaScript and regular expressions. After successful validation, it displays a confirmation message.

**Note:** This assessment uses client-side validation. Registration details are not stored in a database.
